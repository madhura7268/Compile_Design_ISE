# ToyLang Semantic Analysis & Type System Specification

## Overview of Phase 3: Semantic Analysis
Semantic analysis operates on the Abstract Syntax Tree (AST) generated by the parser.
Its primary responsibilities are:
1. Building and managing the scoped Symbol Table.
2. Checking identifier declaration and scope visibility.
3. Performing static type checking and type inference.
4. Detecting duplicate declarations in the same scope.

## Section 1: Lexical Scoping and Symbol Table Rules

### Rule SEM-SCOPE-01: Scope Creation and Destruction
- The program starts in the **Global Scope** (Level 0).
- Every block `{ ... }` enters a new child scope (Level $N+1$).
- Upon exiting the block `}`, the current scope is popped, and symbols local to that block are removed from active lookup.

### Rule SEM-SCOPE-02: Identifier Resolution
- When an identifier `x` is referenced, the compiler searches from the innermost active scope outwards to the global scope.
- If the identifier is found in any enclosing scope, the reference resolves to that symbol.
- If the identifier is not found in any active scope, a `UndeclaredVariableError` is raised.

### Rule SEM-SCOPE-03: Variable Shadowing
- An identifier declared in an outer scope may be declared again in an inner nested scope.
- The inner declaration **shadows** the outer declaration within the inner block.
- Upon leaving the inner block, the outer declaration becomes visible again.

### Rule SEM-SCOPE-04: Duplicate Declaration within Same Scope
- An identifier cannot be declared more than once within the **same** scope.
- Attempting to redeclare `int a;` when `a` is already declared in the current block raises `DuplicateDeclarationError`.

## Section 2: Type System and Type Checking Rules

### Supported Primitive Types
- `int`: 64-bit signed integer.
- `float`: IEEE 754 double-precision floating point.
- `bool`: Boolean value (`true` or `false`, represented as 1 or 0).

### Rule SEM-TYPE-01: Variable Assignment Compatibility
- In an assignment `x = expr;`, the type of `expr` must match the declared type of `x`.
- Assigning a `float` to an `int` variable is a type error (`TypeMismatchError: Cannot assign float to variable of type int`).
- Assigning an `int` to a `float` variable requires explicit coercion or is rejected if strict typing is enforced.

### Rule SEM-TYPE-02: Arithmetic Operators
- Operators `+`, `-`, `*`, `/` require numeric operands (`int` or `float`).
- If both operands are `int`, the result type is `int`.
- If either operand is `float`, the operation promotes to `float`.
- Modulo operator `%` is strictly valid only on `int` operands (`int % int -> int`).

### Rule SEM-TYPE-03: Relational and Comparison Operators
- Operators `<`, `<=`, `>`, `>=` require numeric operands and return type `bool`.
- Operators `==`, `!=` require both operands to have compatible types and return type `bool`.

### Rule SEM-TYPE-04: Conditional Statements
- The condition expression in `if (cond)` and `while (cond)` must evaluate to `bool` or an integer condition (where non-zero is treated as true).

### Rule SEM-TYPE-05: Unary Operations
- Unary minus `-x` requires a numeric operand (`int` or `float`) and preserves the operand type.
